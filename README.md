# Starbooks

STARBOOKS Teacher Orientation — a full-screen web presentation for DOST-STII.

## Features

- Slide deck with keyboard navigation (arrows, space)
- Fullscreen present mode (`F`)
- Download as PowerPoint (`.pptx`)
- Printable teacher manual at `/starbooks-teacher-manual.html`

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Deploy

Configured for [Vercel](https://vercel.com) with Vite. Connect this repository and deploy — build command: `npm run build`, output directory: `dist`.
